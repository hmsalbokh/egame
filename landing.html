الأسئلة الشائعة

هل يعمل بدون إنترنت؟

نعم — الألعاب 100% offline. Admin (رفع Excel) يتطلب اتصال (SheetJS CDN).

هل يمكن تخصيص المفردات؟

نعم — المعلم يرفع Excel (Vocabulary/Sentences/Quiz/Leaderboard) عبر admin.html.

هل يدعم RTL/العربية؟

نعم — UI بالعربية (RTL)، كلمات إنجليزية (LTR).

هل هناك إعلانات؟

لا — بدون إعلانات. (Monetization عبر اشتراكات/رخص).

كيف أرسل تقرير طالب للمعلم؟

الطالب: "نسخ تقرير إنجازي" → إرسال (WhatsApp/Telegram) → المعلم يُدخل في Excel Leaderboard.

📖 دليل المعلم — English Fun

كيفية استخدام English Fun في الفصل (متوسط/ثانوي).

1. الإعداد (5 دقائق)

  • افتح index.html في المتصفح (أو ارفع على خادم).
  • الطلاب يفتحون نفس الرابط (أو embed في LMS).
  • لا حاجة لتسجيل دخول (offline-first).

2. تخصيص المفردات (Excel)

  • افتح admin.html (كلمة مرور: admin123).
  • حمّل excel-template.xlsx، عدّل (Vocabulary/Sentences/Quiz/Leaderboard).
  • ارفع Excel → "تحميل ومعاينة" → "توليد game-data-*.js".
  • للـ multi-stage: أضف 6 مراحل (أول..ثالث متوسط/ثانوي) → ولّد stages.js.
  • ارفع جميع الملفات إلى مجلد الألعاب.

3. في الفصل (10-15 دقيقة)

  • الطلاب يفتحون الرابط → يختارون مرحلتهم.
  • اختر لعبة (مثلاً "وصل الكلمات") → العب.
  • استخدم "اضرب الكلمة" (speed round) للمنافسة.
  • "شنق الرجل" / "ترتيب الحروف" للإملاء.
  • "أسئلة تفاعلية" (tap/drag/build) للتفاعل.

4. تقارير الطلاب (Weekly)

  • الطالب: "📋 نسخ تقرير إنجازي" → ينسخ.
  • يرسل (WhatsApp/Telegram) للمعلم.
  • المعلم: admin → "تحديث أبطال الأسبوع السريع" → لصق التقارير → "تحليل" → preview → "تحميل".
  • رفع `game-data-.js` → لوحة أبطال تُحدّث.

5. Tips & Best Practices

  • استخدم "Revenge Round" (2x XP) للكلمات التي أخطأ فيها الطلاب.
  • SHOP: امنح طلاباً نقاطاً (أو اطلب منهم كسبها) لشراء ثيمات/ألقاب.
  • CHALLENGE: "تحدَّ صديقك" → رابط → منافسة.
  • 100% offline → مناسب للفصول بدون Wi-Fi.
  • لا إعلانات → مناسب للأطفال.

6. استكشاف الأخطاء

  • لا تظهر لوحة أبطال؟ → تحقق من `game-data-.js` (leaderboard array).
  • الألعاب لا تتحرك؟ → تحقق من console (404 = missing stage file → fallback to game-data.js).
  • لا صوت على mobile؟ → first tap unlocks AudioContext (auto).
  • لا تقدم (localStorage)؟ → same browser/device required.
